chore(release): v0.7.0

App and project control on top of the drawing tools, plus every bug the live
sessions exposed.

New tools (83 -> 97): eda_launch / eda_close, project listing/get/open/create/
delete/modify/copy/import/export, close_document, workspace/teams/folders.
Live-verified on EDA 3.2.186 (signed in, semi-offline): launch via explorer,
aggregated local project listing, open by Chinese project name, schematic page
read, project export (1.05 MB), and import creating a real project.
createProject/deleteProject do nothing on this build and are documented as such.

Fixes: extension version injected from extension.json (a stale constant made the
bridge report a mismatch forever), zombie-client routing with liveness + one
read-only retry, liveness-aware connection counts, hoisted optional() so export/
import work, raw team/project payloads instead of empty summaries, team-aggregated
project lookup, reg query /s + missing key separator + cache-key collision, GBK
decoding for registry output, explorer hand-off for launches, pgrep-based process
counting off Windows.

Adds scripts/contract-check.mjs (wired into pnpm check and CI) that cross-checks
tool declarations vs handlers, every called API vs the extension allow-list,
internal helpers, and input schemas.

Wire contract 0.3.5 -> 0.4.0: re-import dsh-eda-bridge-extension-0.4.0.zip.
97 tools, 110 unit tests.
