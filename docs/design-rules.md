# 设计规范（嘉立创EDA 原理图 + PCB）

> 本文件是插件强制/建议遵循的**规范正文**。可量化部分由代码执行（`src/bridge/design-rules.ts`），
> 不可量化部分（分区、布局美学、制造流程）由注入给模型的系统提示（`src/guidance.ts`）引导。
> 核心原则：**不要把工艺极限当作设计默认值**。工艺能力以嘉立创下单页面当日显示为准。

## 0. 插件如何落实这些规则

| 规范条款 | 落实方式 | 违反时 |
|---|---|---|
| 网络命名（§2.1） | 所有带 `net` 参数的工具（`eda_draw_wire`、`eda_place_net_*`、`pcb_draw_track/via`、`eda_pcb_create_pour`）调用 `assertNetName` | 硬错误：空格/斜杠/括号/中文等不可解析字符；警告：非大写 |
| 走线线宽（§5.1） | `pcb_draw_track` 按网络角色给默认线宽并校验；`eda_pcb_set_net_track_width` 同样校验 | 低于 6 mil 报错（`force:true` 可越过）；低于角色建议值给警告 |
| 过孔尺寸（§5.2） | `pcb_draw_via` 按角色给标准孔径并校验焊环/孔径 | 焊环 <0.2mm 或孔径 <0.2mm 报错；孔径 <0.3mm 警告；非标尺寸警告 |
| 铺铜间距（§5.4） | `eda_pcb_create_pour` 返回要求/建议值（API 无法写规则本身） | 提示到 `设计 → 设计规则` 设置 |
| 板框（§7.2） | `pcb_draw_board_outline` 默认 10 mil 线宽 | — |
| DRC（§6） | `eda_pcb_run_drc`；`eda_design_audit` 汇总 | 审计把 DRC 违规计入 `violations` |
| 分区/布局/丝印（§3、§4、§7.1） | 系统提示中的流程与数值约束 | 无自动强制（API 不暴露丝印尺寸/布局评分） |

`eda_design_audit` 是只读体检：一次调用返回 `violations` / `warnings` / `checklist` / 每个网络的最小线宽与角色，
布线前后各跑一次即可。

---

## 1. 总原则

1. **先规则，后布线**：线宽、线距、过孔三项必须在布线前设置。
2. **先分区，后放置**：原理图按功能模块分区，PCB 按信号流向布局。
3. **常规优先，极限慎用**：嘉立创工艺极限可达 4mil 线宽/间距，但常规设计信号线 ≥6mil、过孔 ≥0.3mm。
4. **DRC 不是形式**：原理图 DRC 与 PCB DRC 都必须通过，布通率 100% 后再输出制造文件。
5. **可读性也是设计质量**：分区、丝印方向、网络命名、BOM 完整性都影响调试与生产。

## 2. 原理图设计

### 2.1 网络命名（致命错误级）

- 后端对网络名做**精确字符串匹配**，命名违规会导致网络悬空或导入失败。
- 长度 ≤ **255** 字符；只允许大写字母、数字与可见 ASCII 字符。
- **实践建议**：只用大写字母、数字、下划线。避免空格、括号、中文、减号、斜杠。
  - 差分对不要写 `USB_DP/DM`（斜杠会被当作分隔符拆成两个网络），应分别命名 `USB_DP`、`USB_DM`，再用差分对管理器绑定。
- 网络标识、网络端口、跨页连接标识的名称必须与所连导线/总线名称一致。
- 实现：`checkNetName()` / `assertNetName()`（`src/bridge/design-rules.ts`）。`.`、`+`、`-` 允许（既有工程如 `P0.1` 依赖它），但会给出风格警告。

### 2.2 位号与封装一致性

- 位号（Designator）与网络标号一一对应是硬性门槛。
- 保存前用 **工程 → 网络表检查**，人工核对：原理图位号+引脚 ↔ PCB 焊盘编号 ↔ 实际网络名。
- 插件侧：`eda_pcb_get_components({ includePins: true })` 的 `padNets` 是准确的焊盘网络来源（器件摘要里的 pad/net 在网表导入后可能滞后）。

### 2.3 原理图 DRC

- 绘制完成后必须执行 `eda_run_drc`，先使用默认规则，无报错、无警告再转 PCB。
- 常见致命错误：同一引脚编号未接同一网络；引脚端点重叠但未连接；网络端口/标识与导线名不一致。

## 3. 原理图放置与分区

### 3.1 功能模块划分

| 模块 | 内容 |
|---|---|
| 电源 | 稳压器（LDO/DC-DC）、滤波电容、保护器件集中放置 |
| 控制单元 | 主控芯片 + 外围（去耦、晶振、复位）围绕主芯片 |
| 接口 | USB/串口/传感器接口各自成区，靠图纸边缘 |
| 信号处理 | 模拟（放大、滤波）与数字（高速、时钟）尽量分开 |

### 3.2 九宫格参考（软约束）

| 区域 | 定位 | 典型 |
|---|---|---|
| 左上 | 输入电源/接口 | Type-C、DC IN、充电 |
| 中上 | 时钟/复位 | 晶振、RC 复位 |
| 右上 | 状态/调试 | LED、调试排针 |
| 左中 | 电源转换 | DC-DC、LDO、滤波 |
| 正中 | 主控核心 | MCU + 去耦 |
| 右中 | 射频/传感器 | Wi-Fi/BLE、IMU、GNSS |
| 左下 | 电池/接地 | 电池连接器、接地汇流 |
| 中下 | 外设 IC | EEPROM、RTC、Hub |
| 右下 | I/O 连接器 | 排针、FPC/FFC |

### 3.3 信号流向

- 总体：从左到右、从上到下；输入在左、输出在右；电源在上、地符号在下。
- 主控居中，去耦电容、晶振紧贴主芯片符号（与 PCB 物理邻近关系一致）。

### 3.4 多图页与层次化

- 单页放不下时用多图页（电源页/MCU 页/接口页）或层次化 Block，不要挤压在一页。

### 3.5 视觉强化

- 每个功能区用无电气属性的折线框住（`eda_draw_functional_box` 可按器件包围盒自动画虚线框）。
- 框旁加文本标注（`eda_draw_text`）；不同信号类型可用颜色区分。

### 3.6 布局传递

- 框选功能分区 → `Ctrl+Shift+X`（布局传递）把器件传送到 PCB 并聚集，便于模块化布局。
- 插件等价能力：`eda_pcb_move_component` 按坐标精确摆放；`eda_pcb_get_components` 取现有位置。

## 4. PCB 布局

### 4.1 优先级

1. 安装孔（先放，锁定板框约束）；
2. 板边接口（USB/电源/天线靠边、开口朝外）；
3. 主芯片（居中偏上，下方留走线空间）；
4. 配套器件（去耦、晶振就近围绕）。

### 4.2 关键器件

| 器件 | 要求 |
|---|---|
| 去耦电容 | 紧贴电源引脚，距离 ≤2mm；小容量最近、大容量稍远 |
| 晶振 | 靠近晶振引脚，避免板边；区域底层净空 |
| 发热器件 | 靠板边；热焊盘下打散热过孔阵列（0.3mm 孔径、间距约 1mm） |
| 电解电容 | 与高温器件 ≥5mm |
| 模拟/数字 | 单点汇合（星形接地）；ADC/DAC 靠模拟区，远离时钟与开关电源 |
| 天线区 | 净空：无铜、无器件 |

### 4.3 元件间距底线

| 场景 | 最小 |
|---|---|
| SMD–SMD | 0.2mm |
| SMD–通孔 | 0.5mm |
| 器件–板边 | 0.5mm（推荐 1mm） |
| 器件–V-Cut | 1.5mm |

## 5. 布线

### 5.1 线宽（1oz）

| 网络角色 | 推荐 | 插件默认 |
|---|---|---|
| 普通信号 | 0.15mm ≈ 6mil | 6 mil |
| 分支电源 | 0.25mm ≈ 10mil | 16 mil（角色默认取主干档，可显式传 10） |
| 主干电源 | 0.4mm ≈ 16mil | 16 mil |
| 大电流 >500mA | 0.5mm ≈ 20mil | 20 mil（`eda_pcb_set_net_track_width`） |
| GND 走线 | 首选铺铜；必须走线时同大电流档 | 16 mil + 警告提示优先铺铜 |

- 极限是 4mil，**不要当作默认值**。
- 线宽用 0.05mm 步进圆整（0.15/0.2/0.25/0.3/0.4/0.5mm），避免 0.127mm 之类 mil 碎值。

载流参考（1oz）：0.15mm≈0.5A(外层)/0.3A(内层)，0.25mm≈0.9A/0.5A，0.5mm≈1.5A/0.8A，1.0mm≈2.5A/1.5A。

### 5.2 过孔

| 内径/外径 | 用途 |
|---|---|
| 0.2/0.4mm | 常规信号 |
| 0.3/0.6mm | 电源、GND 等载流 |
| 0.4/0.8mm | 大电流 |

- 焊环 ≥0.2mm；免费打样通常要求孔径 ≥0.3mm。
- 高速换层就近打地孔；差分换层 = 2 信号孔 + 2 地孔紧邻；禁止 via-on-pad（除非填孔盖铜工艺）；BGA 优先狗骨扇出。

### 5.3 特殊信号

| 信号 | 要求 |
|---|---|
| USB D+/D- | 尽量顶层、少换层；USB 2.0 差分阻抗 90Ω |
| 晶振 | 短、直，避免底层；顶层包地净空 |
| 差分对 | 非耦合区调整等长；按阻抗设对间间距 |
| 电源 | 按电流加粗，流向清晰 |

### 5.4 铺铜

- 顶层/底层铺 GND，优先保证完整。
- 与所有非同网络对象间距 **≥6mil（0.152mm）**，实际建议 ≥10mil（0.254mm）。
- 移除孤岛（死铜形成天线）；网格铺铜间距 ≥0.254mm、网格线宽不可过细。

## 6. DRC

### 6.1 三项基础规则（布线前）

线宽、线距、过孔（`设计 → 设计规则`）。

### 6.2 参考值

| 项目 | 建议 |
|---|---|
| 最小线宽 | ≥6mil（0.15mm） |
| 最小间距 | ≥6mil |
| 过孔孔径 | ≥0.3mm |
| 孔到线 | ≥0.2mm |
| 元件间距检查 | 全选 |

### 6.3 检查

- 布线中开启实时 DRC；完成后 `工具 → 检查 DRC`（插件：`eda_pcb_run_drc`、`eda_design_audit`）。
- 确认：信号全连通、无开短路、未进禁布/限高区、规则优先级正确。
- 旧 PCB 文档可能默认关闭实时 DRC，需要手动开启。

## 7. 丝印、板框、输出

### 7.1 丝印

- 字符高度 ≥1.0mm（常用 0.8–1.5mm），线宽 ≥0.15mm。
- 全板朝向不超过两个；位号清晰、不压焊盘、不落到阻焊开窗。

### 7.2 板框

- 画在板框层，线宽常用 10mil（插件默认值）。
- 原点建议在矩形板框左下角；圆角常用 2mm；完成后锁定板框。

### 7.3 输出前

- 布通率 100%、无悬空网络；焊盘与走线连接处加泪滴。
- 输出：Gerber、装配文件（ASM）、SMT 贴片文件、工艺说明。
- BOM 至少含：器件名称、位号、数量、封装、值、嘉立创商品编号。

## 8. 嘉立创工艺与免费打样（参考）

| 项目 | 参考 |
|---|---|
| 免费打样层数 | 常见 1–2 层 |
| 免费尺寸 | 通常 10×10cm 内 |
| 板厚/铜厚 | 1.6mm / 1oz |
| 免费线宽/间距 | ≥6mil |
| 免费孔径 | ≥0.3mm |
| 工艺极限 | 1oz 下 4mil 左右（非默认） |

## 9. 打样前检查清单

- [ ] 原理图 DRC 无致命错误
- [ ] 网络名只含合法字符（字母/数字/下划线/点/加号/减号），无中文、空格、斜杠
- [ ] 网络标识/端口/跨页标识与导线名一致
- [ ] 位号与封装引脚映射核对，无网络悬空
- [ ] 原理图已分区并加线框/文本标注
- [ ] 主控居中，去耦与晶振贴近
- [ ] 复杂工程用多图页/层次化
- [ ] 板框已锁定，安装孔/对外接口位置固定
- [ ] 去耦 ≤2mm、晶振区域净空
- [ ] 模拟/数字分开，地单点汇合
- [ ] 线宽、线距、过孔规则已设置
- [ ] 信号线 ≥6mil、过孔 ≥0.3mm、孔到线 ≥0.2mm
- [ ] GND 铺铜完整、孤岛移除、间距 ≥6mil（建议 10mil）
- [ ] 丝印高度 ≥1mm、线宽 ≥0.15mm、方向统一、不压焊盘
- [ ] DRC 全通过、布通率 100%
- [ ] Gerber + BOM + 装配文件已导出
- [ ] 已用 `Ctrl+Shift+X` 布局传递（如适用）

## 10. 推荐工作流

1. 规划功能分区与信号流向。
2. 画原理图（九宫格/功能流；左输入右输出、上电源下地）。
3. `eda_run_drc`，核对位号与网络映射。
4. 布局传递（`Ctrl+Shift+X`）或 `eda_pcb_move_component` 精确摆放。
5. PCB 布局：安装孔 → 板边接口 → 主控 → 配套器件。
6. 设置规则（线宽/线距/过孔/孔到线/元件间距）。
7. 布线：`eda_pcb_auto_route`（异步，`eda_pcb_job_status` 轮询）或 `pcb_draw_track`（线宽按角色）。
8. 铺铜：`eda_pcb_create_pour`，去孤岛、留间距。
9. `eda_pcb_run_drc` + `eda_design_audit`，直到 `ok: true`。
10. 丝印与板框检查，锁定板框。
11. 导出 Gerber/BOM/装配文件（`eda_pcb_export_gerber`、`eda_export_bom`）。
12. 对照 §9 清单复核，工艺以嘉立创下单页面为准。
